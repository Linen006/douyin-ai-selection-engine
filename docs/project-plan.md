# 抖音 AI 选品剪辑引擎（douyin-ai-selection-engine）项目方案

版本：v0.1（草稿）  
日期：2026-09-02  
定位：可演示的作品集 MVP，用于学习“从需求到落地”并支撑 AI 应用开发方向求职。

## 1. 定位与诚实边界

- 这是一个“可解释的选品 + 素材合规审核 + 人工复核 + 风险报告”闭环，不是“全自动爆单系统”。
- 不硬爬抖音、不伪造真实销量数据、不承诺转化效果。
- 数据以离线样例和用户导入为主；LLM 调用支持真实 DeepSeek 与离线 Mock 双模式。
- 视频剪辑只做可控的简单处理（裁切、拼接、画面处理、字幕为后期增强）。

## 2. 技术栈与运行环境

- Python 3.12 + Flask + SQLite + 原生 HTML/CSS/JS
- DeepSeek API（OpenAI 兼容格式，结构化输出）
- ffmpeg：优先使用系统 PATH 中的 ffmpeg/ffprobe；找不到时回退到 `imageio-ffmpeg` 自带的 ffmpeg
- Pillow、requests、python-dotenv、pytest
- 运行目录：`douyin-ai-selection/.venv`（已创建）
- 对外仓库名：`douyin-ai-selection-engine`；中文名用于 README、界面与文档

## 3. 主流程（v1 闭环）

```text
导入商品/素材数据
  → 选品规则打分（硬性过滤 + 多维评分 + 可解释原因）
  → 素材审核（规则检测 + LLM/Mock 辅助 + 风险分级）
  → 人工复核（高不确定项人工确认）
  → ffmpeg 简单剪辑（编辑计划 JSON + 成片）
  → 风险报告输出（商品信息 + 素材信息 + 删除记录 + 成片）
```

## 4. 模块与规则翻译

### 4.1 选品规则引擎（scoring）

规则来源：需求文档“第一部分：AI 自动选品模块”。先做硬性过滤，再做维度打分，输出 S/A/B/C 推荐等级。

硬性淘汰条件（任一命中默认淘汰，行为可配置）：

- 类目黑名单：大家电、家具、大型设备、珠宝、黄金、手表、品牌独家、食品、酒水、生鲜、保健品、化肥/营养液、医疗相关、功效美容、婴幼儿高风险用品。
- 类目限制：白名单类目中的“不选”子类。
- 标题/类目含版权、品牌独家、旗舰店自研、单店独家等信号。

黑名单处理原则：淘汰不等于删除。命中硬性条件的商品仍保留在商品池并展示原因，但默认不会自动进入素材/剪辑环节；是否允许人工放行由配置决定（默认禁止，可开启 `allow_blacklist_review`）。这样既符合“全部过滤”，又保留可解释性，也便于演示“为什么高分商品不能用”。

评分维度（默认初值，后续用样例调优）：

| 维度 | 权重 | 主要信号 |
|---|---|---|
| 销售表现 | 30 | 近 7 天成交、视频成交占比、转化率 |
| 同款开放度 | 20 | 同款店铺数、销量梯度 |
| 增长/稳定 | 15 | 上架时间、增长状态 |
| 可复制性 | 15 | 供应链易复制、售后简单、客单价 |
| 视频可展示性 | 10 | 卖点易展示、家庭场景 |
| 合规风险 | 10 | 词/类目/功效风险 |

说明：文档阈值（视频成交占比 >50%、转化率 >=15%、同款店铺 >=5 等）作为初始阈值放入规则配置，供测试与人工调整。

### 4.2 素材审核（audit）

规则来源：需求文档“第三部分：素材审核规则”。v1 基于文本/元数据做规则检测，不做真实逐帧视觉识别。

检测项：

- 价格内容：9.9 元、19.9 元、秒杀、最低价、优惠价等。
- 极限词：最、第一、顶级、唯一、绝对、100% 等。
- 功效夸大：治疗、疾病、美白祛斑、虚假效果等。
- 明星/网红/直播切片/影视人物关键词。
- 水印/Logo：博主昵称、平台水印、防伪水印、品牌词。
- AB 货风险：展示商品与销售商品不一致风险，默认进入人工复核。
- 画面风险：v1 人工标注为主，规则只做提示。

每次检测输出：检测项、命中证据、风险等级（低/中/高）、建议动作（通过/淘汰/人工复核）。

### 4.3 AI 剪辑（editor）

规则来源：需求文档“第四部分：AI 自动剪辑模块”。

- v1 输入：已审核通过的素材文件（本地）+ 元数据。
- v1 能力：按时间点裁切、拼接，统一输出规格；生成编辑计划 JSON。
- v1 不自动添加口播/字幕/转场；字幕等作为后续增强。
- ffmpeg 可执行文件解析：`FFMPEG_BIN` 环境变量 → PATH → `imageio_ffmpeg.get_ffmpeg_exe()`。
- 演示素材：可用 ffmpeg 生成合成测试短片（testsrc + tone），避免依赖真实版权素材。

### 4.4 人工复核（review）

- 自动审核无法判定、品牌无法判断、AB 货风险、产品功能争议、人物身份存疑时进入人工队列。
- WebUI 提供“通过/淘汰/修改风险等级 + 备注”，复核后状态固化。

### 4.5 报告输出（report）

- 商品卡片：名称、链接、图片、类目、得分明细、推荐等级、淘汰/通过原因。
- 素材报告：来源、点赞/评论、发布时间、审核结果、风险证据。
- 成片报告：成片路径、编辑计划、删除记录、剩余风险、人工复核记录。
- 格式：JSON（结构化）+ Markdown/HTML（可读）。

### 4.6 WebUI 与 CLI

WebUI 页面：

- `/` 工作台总览
- `/products` 商品池与选品评分
- `/materials` 素材审核与人工复核
- `/jobs` 剪辑任务
- `/reports` 报告查看/下载

界面语言：v1 先保证中文完整，界面文案集中管理，预留中英切换；能低成本支持英文键就一起做，实在不行默认中文。

CLI（示意）：

```text
python -m app.cli demo              # 一键跑通样例（Mock）
python -m app.cli score --import data/sample/products.csv
python -m app.cli audit --material-id 1
python -m app.cli edit --job-id 1
```

## 5. 数据表草案

| 表 | 核心字段 |
|---|---|
| products | 标题、链接、图片、类目、价格、近7天成交、视频成交占比、转化率、同款店铺数、上架时间 |
| score_details | 商品、维度、得分、权重、原因、是否硬性淘汰、推荐等级 |
| materials | 商品、素材来源、视频文件/链接、点赞/评论/发布时间、素材文本、状态 |
| audit_checks | 素材、检测项、命中证据、风险等级、建议动作 |
| review_tasks | 待复核对象、来源、状态、备注、复核人/时间 |
| edit_jobs | 商品、编辑计划 JSON、状态、输出路径、创建/完成时间 |
| edit_clips | 任务、素材、时间范围、顺序、裁切参数 |
| reports | 商品/任务、报告类型、JSON/MD/HTML 路径、生成时间 |

## 6. MVP 里程碑

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M0 骨架 | 项目结构、SQLite schema、样例数据、一键 demo 脚本 | 无 AI 也能跑通流程 |
| M1 选品 | 规则配置、评分引擎、评分页、pytest | 样例商品可见原因与等级 |
| M2 审核+复核 | 规则检测、风险分级、人工复核队列 | 素材可审核、可人工处理 |
| M3 剪辑+报告 | ffmpeg 合成短片、编辑计划、风险报告 | 能产出成片和报告文件 |
| M4 真实 AI | DeepSeek 结构化调用 + Mock 切换、README、开源准备 | Key 只存 `.env` |

## 7. v1 明确不做

- 不爬抖音/抖音后台数据。
- 不做真实逐帧画面识别（无 OCR/视觉模型）。
- 不做自动发布、自动下单。
- 不做完整混剪叙事、口播、字幕特效。
- 不承诺爆单或收益。

## 8. 决策记录

- 核心卖点：可解释选品 + 素材合规审核 + 人工复核 + 风险报告。
- 技术栈：Python + Flask + SQLite + DeepSeek + ffmpeg + HTML/JS + pytest。
- 剪辑后端：ffmpeg 为主；剪映自动化保留为可选增强。
- 数据：离线样例 + 导入；不硬爬。
- 命名：仓库 `douyin-ai-selection-engine`；中文标题用于展示。
- 演示素材：v1 先用 ffmpeg 生成合成测试短片，后续可替换真实本地素材。
- 界面语言：默认中文，文案集中管理并预留中英切换。
- 黑名单：淘汰但保留在池中并说明原因，默认不进下游，可配置人工放行。
